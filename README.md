## 任务提示词

以下为本题完整的 User Prompt 原文，两次执行必须使用完全相同的文本。

我们的报表视图每次全量重算代价太高，希望基表变化时只更新受影响的部分。请从零实现一个增量物化视图维护组件。仓库目前只有一个空的 Maven 工程（pom.xml 只声明 JUnit 5 与 AssertJ）。要求：1) 支持定义视图：基于一个或多个基表的聚合结果（计数、求和、最大值）；2) 支持增量维护：基表插入、删除、更新时按影响条目更新视图，不得全量重算，需给出更新条数与全量重算的对比；3) 支持最大值这类不可逆聚合的特殊处理：删除当前最大值时要能重新取次大值，需说明实现方式；4) 正确性：增量维护后的视图必须与全量重算结果完全一致，需用随机操作序列验证；5) 支持批量变更合并：同一批内多个变更合并成一次视图更新；6) 支持视图过期与重建：视图落后过多时可强制重建，重建期间旧视图仍可读；7) 提供统计：视图更新次数、受影响条目数、重建次数与落后版本数；8) 测试覆盖三类聚合、增删改维护、最大值回退、批量合并、重建期间可读与正确性验证；`mvn -q verify` 一条命令跑通。
